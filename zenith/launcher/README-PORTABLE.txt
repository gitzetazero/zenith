Zenith Launcher (powered by XMCL) - versión portátil
=====================================================

Descomprime esta carpeta donde quieras (mejor una ruta corta) y abre
«Zenith Launcher.cmd». Equivale a ejecutar «zenith-bridge.exe start».

Primera vez
  1. Abre «Zenith Launcher.cmd». XMCL te pedirá la carpeta de datos: elígela.
  2. Cierra XMCL del todo y vuelve a abrir «Zenith Launcher.cmd»: así se crea
     la instancia «Zenith».
  3. En XMCL inicia sesión con tu cuenta de Microsoft (debe tener Minecraft:
     Java Edition), elige la instancia «Zenith» y pulsa Jugar.

Qué es y qué no es portátil
  - XMCL no tiene modo portátil: sus datos (el fichero %APPDATA%\xmcl\root y
    la carpeta de datos que elijas) y los de Zenith (%APPDATA%\zenith) se
    guardan en tu perfil de Windows aunque esta carpeta esté en un pendrive.
    Borrar esta carpeta no los borra.
  - Si mueves esta carpeta, vuelve a abrir «Zenith Launcher.cmd»: la instancia
    se rehace apuntando a la nueva ubicación.

Actualizaciones
  - El juego (Zenith) se actualiza solo al pulsar Jugar, tras verificar su firma.
  - XMCL se actualiza con su propio actualizador, que solo sustituye
    resources\app.asar. Para renovar el puente, descarga un paquete nuevo.
